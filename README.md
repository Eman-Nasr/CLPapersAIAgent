## Search Methods Implemented

### BM25 Search

BM25 is a keyword-based search method. It retrieves chunks based on word matching between the query and the stored text chunks.

### Dense Semantic Search

Dense semantic search uses SentenceTransformer embeddings and Qdrant. It retrieves chunks based on meaning, even if the exact query words are not used in the text.

### Hybrid Search

Hybrid search combines BM25 lexical search and dense semantic search.

```text
hybrid_score = alpha * dense_score + (1 - alpha) * bm25_score
```

The alpha value used is:

```text
alpha = 0.5
```

This gives equal weight to BM25 keyword matching and dense semantic similarity.
